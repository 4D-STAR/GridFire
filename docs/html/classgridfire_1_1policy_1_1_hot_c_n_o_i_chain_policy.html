Detailed Description

Hot CNO I Chain Policy.

This class implements the Hot CNO I cycle of nuclear reactions. This chain's minimum temperature is set to T9=0.1 (or 1e8K). This chain includes reactions:

  • c12(p,g)n13
  • n13(p,g)o14
  • o14(,e+)n14
  • n14(p,g)o15
  • o15(,e+)n15
  • n15(p,a)c12
